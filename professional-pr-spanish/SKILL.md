# Professional Puerto Rican Spanish

## When this runs

This skill only runs when the user calls it by name. Translate the text the user gave along with the request. If they called the skill without any text, ask them to paste the text they want translated and do nothing else until they do.

## The goal

Write the way a bilingual professional in a San Juan office writes a work email. Not textbook Spanish, not Spain or Mexico Spanish, and not street slang.

In Puerto Rico, a lot of work vocabulary is said in English, especially tech, media, marketing, design, and office terms. Translating those into "proper" Spanish makes the text sound foreign or stiff to a Puerto Rican reader.

There are two ways to get this wrong:

1. **Over-translating.** Writing "ordenador portátil", "enlace", "archivo fuente", or "equipo de medios" when a PR professional would say "laptop", "link", "source file", or "media team".
2. **Over-localizing.** Adding slang to make it sound "Boricua": "wepa", "pana", "brutal", "janguear", "chavos", "corillo", "acho", "bregar", "ay bendito". Never add slang. This is for work.

## How to translate

1. Read the source and match its tone and formality. Don't make it warmer, more formal, or longer than the original.
2. Find the terms of art: tech, software, file types, media, marketing, design, and office jargon. For each one ask: would someone in a PR office say this in English? If yes, keep it in English.
3. Translate everything else into clear, normal Spanish.
4. Read it back. Would a bilingual coordinator in San Juan send this in a work email? If it sounds like a textbook or a dubbed movie, fix it.

## Usually keep in English

Tech: PC, laptop, desktop, mouse, software, app, link, email, password, login, username, Wi-Fi, website, screenshot, dashboard, download (hacer download), folder, shared folder, reset (hacer reset), Zoom, Teams, Excel, PDF, JPEG.

Media, design, marketing: media team, source file, placement, layout, mockup, template, branding, flyer, brochure, banner, post, stories, engagement, influencer, webinar.

Office and work: deadline, feedback, follow-up, meeting (reunión is also fine), onboarding, part-time, full-time, overtime, freelance, PO, startup.

"Archivo" is normal for a generic file ("el archivo JPEG"). Keep "file" in English when it's part of a fixed term like "source file".

## Use Puerto Rican Spanish, not other regions

| Use | Not |
|---|---|
| computadora | ordenador |
| laptop | portátil, ordenador portátil |
| celular | móvil |
| carro | coche, auto |
| estacionamiento (or parking) | aparcamiento |
| mercadeo (marketing is also fine) | mercadotecnia |
| adiestramiento | capacitación, formación |
| link | enlace, vínculo |
| email (correo electrónico in formal docs) | correo-e, mail |
| archivo | fichero |
| planilla (tax return) | declaración de la renta |
| licencia de conducir | carné, permiso de conducir |

Never use Spain markers like "vale" (as "okay"), "vosotros", or "móvil", or Mexican/South American markers like "ahorita", "platicar", "checar".

## How to write the English terms

- Use them like normal words. No italics, no quotes, no Spanish explanation in parentheses.
- Lowercase unless it's an acronym or a brand.
- Give them a Spanish article. Most are masculine: el email, el link, el source file, el placement, el layout, el deadline, el feedback, el follow-up, el meeting, el software, el screenshot. Some common feminine ones: la laptop, la app, la PC.
- Pair English nouns with Spanish verbs. Write "le envío el link", "reenviar el email", "imprimir el flyer". Avoid hybrid verbs like "textear", "printear", "forwardear", "deletear" in anything client-facing. "Chequear" is fine.

## Conventions

- **Numbers:** US style, decimal point and comma for thousands: 5.83, 1,500.
- **Money:** $1,500 (US dollars, symbol first).
- **Units:** keep whatever the source uses. Don't convert inches to centimeters unless asked.
- **Dates:** write the month in words to avoid confusion: 13 de octubre de 2026.
- **Greetings and closings:** "Hola:", "Buenos días:", "Saludos,", "Gracias,". Use a colon after the greeting, Spanish style.
- **"Déjeme saber"** is normal and correct in PR business writing. Keep it.
- **Usted vs. tú:** usted with clients, vendors, external contacts, and anyone senior. Tú only if the source is clearly casual and between coworkers.

## Adjust for the audience

- **Business, marketing, tech, internal emails:** follow everything above.
- **Government, legal, or official documents:** lean more formal. Use Spanish terms where a standard one exists (correo electrónico, enlace, fecha límite), since PR government and legal writing is more formal Spanish. Keep only terms with no good Spanish equivalent.

## Output

Give the translation ready to copy and paste. Then add one short line listing the English terms you kept, so the user can swap any they don't want:

> Términos en inglés: media team, source file, placement

Skip that line if no English terms were kept, or if the user asks for the translation only. If a term could go either way, use the more common one in PR office speech and mention the alternative in that line.

## Example

This example shows the principle, not a list of terms to reuse. Don't push "media team" or "placement" into other texts. Decide each term on its own, and if a text has no real terms of art, it should come out almost all in Spanish.

**Source:**

> Hello,
> Yes! The half page dimensions (A5) are: 5.83 × 8.27 in (148 × 210 mm). Our media team is kindly requesting both the jpeg file and source file to ensure proper placement in the program. Let me know how else I can help.
> Best,

**Too textbook (don't do this):**

> Hola:
> ¡Sí! Las dimensiones de media página (A5) son: 5.83 × 8.27 pulgadas (148 × 210 mm). Nuestro equipo de medios le solicita amablemente tanto el archivo JPEG como el archivo fuente para asegurar la colocación correcta en el programa. Déjeme saber en qué más le puedo ayudar.
> Saludos,

**Correct:**

> Hola:
> ¡Sí! Las dimensiones de media página (A5) son: 5.83 × 8.27 pulgadas (148 × 210 mm). Nuestro media team le solicita amablemente tanto el archivo JPEG como el source file para asegurar el placement correcto en el programa. Déjeme saber en qué más le puedo ayudar.
> Saludos,
>
> Términos en inglés: media team, source file, placement

What changed: "equipo de medios", "archivo fuente", and "colocación" are correct Spanish, but nobody in a PR media or design office says them. "Archivo JPEG" stays in Spanish because "archivo" is the normal word for a generic file.
